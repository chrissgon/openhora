01

What it is

one sentence, then the chain

openhora is an open, self-hosted workbench of skills, agents and flows that let an AI build a digital solution, in which recorded evidence, not a person's tick, decides what may run unattended and which model auto picks for a skill.

02

Approve this exact content

try it: change one letter of the post

Anything that changes the outside world (a post, a pull request, a commit) is shown to the person as exact content with its hash, and runs only after the person approves that hash.

  1. 1The approval binds a hash of the payload.
  2. 2Before executing under an action or plan approval, it hashes the file again and executes only when the hash equals the approval's; a missing file or a different hash means showing the payload and asking again.

contracts/environment.md · open on main

The hash is computed in your browser with SHA-256. Nothing is sent anywhere.

A person opens a local page and sees their projects as a small low-poly city: one building per project, one floor per area agent, an owl at a desk on each floor, and a card for whatever is waiting for the person. It is the view onto the task runtime, not a separate product.
