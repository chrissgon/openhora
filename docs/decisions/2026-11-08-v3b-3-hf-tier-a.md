## 2026-11-08: tier A: the wrapper, the admission run and the allowlist (V3b-3, steps 7.1 to 7.7; no measurement change, no skill changed, no lab run)

**What.** A component of the HyperFrames registry can become an `hf:` tier-A overlay only through code that fails closed. `hyperframes-image/hf_wrap.py`
holds the admission lint (the closed codes of section 7.1 of the spec) and the wrapper (a scope, a guarded `window` and `document`, nested timeline).
`hyperframes-image/hf_compat.py` runs, inside the HyperFrames image with no network, 67 planted escapes (at least one per lint class, each with the code it must be refused with, plus
the runtime cases of the spec) and a clean control before it gives any component a verdict; one admitted escape fails the run (`planted_escape_admitted`) and no
report is written, and there is no option that skips this. `hyperframes.py compat` mounts a survey folder read-only and copies the report back.
The composer writes a placeholder and a row of `instances.json` for a tier-A beat; `hf_render.py` reads the files from the image's registry folder, checks
each sha256, lints again, wraps, and refuses `tier_a_file_missing`, `tier_a_hash`, `block_lint` and `block_escaped`. `registry.sha256`,
`fetch_registry.py` and the two Dockerfile hook lines bake the registry's LICENSE (and, later, the admitted files) into the image at the pinned commit.

**Why.** Plan V3b row, section 7 of `SPEC-video-V3b`, decisions VD3, VD9, VD12 and D7 of V3a-image (registry files come with V3b). Settled by the
supervisor on the spec's recommendation (not the maintainer's word): OPEN-6 (the `notice` of an `hf:` block is a pointer in our words), OPEN-7 (tier A
admits overlays only; a caption is `caption_tier_b_only`), OPEN-8 (`preset: null` blocks are listed, not drawable in M1), OPEN-14 (the survey is
`registry/components/*` text files at the pin), OPEN-15 (two image builds). The survey was approved by the maintainer ("Sim", STOP B-survey) and run by the
supervisor; it holds 238 components, 855 files, 5,225,571 bytes (83 rows not fetched).

**Review of PR #780 at b13dd806 and its fixes (V3b-3 fix round).** An independent review read the first head. Each finding below has a planted case or a
test that fails without its fix.
1. *The timeline key hid code.* The allowed `window.__timelines[<key>] = ...` took up to 80 arbitrary characters and the lint deleted the whole match
   before any rule ran, so a forbidden call inside the key linted clean. The key is now a quoted `[\w-]{1,64}` string or a bare identifier, and the match is
   replaced by a space (planted: a `Math.random()` call in the key).
2. *The component held the page's real `gsap`* (random and shuffle utilities, `"random(...)"` values, `delayedCall`, `ticker`, `globalTimeline`,
   `config`, `registerPlugin`, `exportRoot`; bare tweens land on the global timeline, which seeking does not drive). It now receives a frozen facade:
   `timeline` and a pruned `utils`. The lint refuses any other `gsap.` member (`gsap_api`) and GSAP's own `random(` and `from: "random"` forms
   (`nondeterministic`). The component's `Math` is a frozen copy whose `random` stops it, and the page's own `Math.random` is replaced by a seeded one
   before any tier-A script runs. `Date.now` and `performance.now` are not replaced page-wide: HyperFrames' own page code may wait on them, so the
   component's `Date` and `performance` are shadowed by objects that stop it instead.
3. *The guard was unproven.* All 51 planted cases were lint-refused, so the browser guard never ran and `guard_unavailable` was never raised. The run now
   runs the control through the guard (it must run to the end), and each planted escape that acts at run time through the guard with the lint bypassed
   (`wrap_unchecked`, used by the compatibility run only; it must answer `escaped-refused`).
4. *Spellings past a text lint.* `\u` and `\x` escapes in a script are refused; the lint scans the raw text and a copy with comments replaced by a space;
   a computed member access whose key is not a plain number is refused.
5. *A script is pasted into a function body.* A script whose brackets, strings, template literals, comments or regular expressions do not balance is
   refused (`unbalanced`), by a small scanner.
6. *Writes outside the component's own objects.* The `prototype` token is refused, except in `Object.prototype.hasOwnProperty.call(` and
   `Object.prototype.toString.call(` (121 of the 238 survey components borrow the first).
7. *Local resources.* Every `url(` but `url(#id)` is refused; an `href` is only a `#` reference; any `src` is refused; markup tags are checked against an
   allow-list (the safe HTML tags and the SVG drawing primitives: no `image`, `feImage`, `meta`, `link`, `iframe`).
8. *Planted cases carry their expected code*, and the test and `try_planted` assert that code is in `lint(html)`.
9. *A tautology in a test was removed.*
10. *`block_escaped` no longer depends on the log alone.* The guard sets `window.__hfEscape` and the attribute `data-hf-escape` on the document
    element, which a step that loads the page can read (the measure step of V3b-2 is the one that does; this part does not edit it). The log marker is
    also kept past the log's cap: `run_render` appends it when it sees it in the stream.
11. *`fetch_registry.py`*: a one-token manifest line exits with a clean message and a duplicate path is refused.
12. *`check_survey`*: a path that goes through a link is refused with the real path in the reason.
13. *`hf_compat.py` and `hf_wrap.py` are loaded inside `compat`*, not when `hyperframes.py` is imported.
14. *`enum` (the maintainer's word, "Siga sua recomendacao", on the supervisor's recommendation):* a declared enum variable is a `choice` parameter whose
    options are the component's own declared `value` strings; each must be a closed identifier of at most 32 characters, with no repeat; an enum with
    no options, more than 20, or any other value is refused `variables_untyped`; a declared default must be one of the options. The labels (prose) are never read.

**Principle 11.** The admission lint, the planted-escape refusal, the sha256 check of every registry file and the lint again at draw time are code; the
wrapper's guard (strict mode, a frozen `window` Proxy whose writes throw, shadowed network, timers, clock and storage, the instance's own `document`) is
code and its throw also marks the log, so a component that catches the error still fails the render. What code cannot see, such as a visual that hides
text, is the C10 contact sheet: a maintainer's judgement. The lint is text-level and refuses a token in a comment too: a pattern that strips comments is
the way a lint is walked around.

**Saving and loss.** (1) Only the two files a block needs (`<name>.html`, `registry-item.json`) are pinned and baked, not every file of a component: it
saves bytes in the image and in the review, and loses nothing the wrapper reads (a component that needs another file is refused, since a relative `src`
or `link` is a lint refusal). (2) `enum` variables are `choice` parameters (the maintainer's word), the parameter type the blocks schema already has; a refusal of odd options loses the
components whose option values are not identifiers. (3) `window.__timelines = window.__timelines || {}`, the registry's own idiom, is
allowed beside `window.__timelines[id] = tl` and the guard accepts exactly that write of the same object: it admits the idiom every component uses and
nothing else written to `window`. (4) A component that declares no variable but reads `getVariables` is refused `variables_untyped`: fail closed over a guess
about its inputs.
(5) The strict computed-key rule, the supervisor's instruction, costs the largest share of candidates (13 pass against 26 with a quote-only rule): it
saves a class of spellings no text lint can follow and loses components that index arrays by a variable.
