## 2026-10-28: the selector's data-file naming rule skips the package goldens and the ledger (BATCH-KEEPER select-data-files; no model call, no lab run, fingerprint unchanged)

Reported by the BL7-4 executor: rule 4 of `scripts/select_tests.py` (`Repo.data_files_naming`) links a module to the data files that quote its stem as a whole string, because a module loaded by a name read from data has no import edge. A package golden under `runtime/tests/entry_ext/` holds traces that quote module stems (for example `interpreter`), so a change to `runtime/interpreter.py` read as "named by a data file that no test names" and selected the whole `runtime/tests` folder (rule 5), which breaks `scripts/tests/test_select_tests_oracle.py::test_vacuity_a_selection_that_drops_the_entry_replay_is_caught_and_names_the_module`.

- **Change.** `data_files_naming` skips every file under `DATA_NAMING_SKIP`, that is `runtime/tests/entry_ext/` and `runtime/tests/expected/`. Both folders are rows of `DATA_FOLDERS`, which already maps a change to their files to the tests that read them (the replays, the ledger tests), so they are not a link from a module to a loader. Every other data file (for example `runtime/natural_languages.json`) still links a module as before. `runtime/phrases_parts/` is not in the skip list: its files quote phrase keys, not module stems, and the brief named two folders.
- **Tests** (`scripts/tests/test_select_tests.py`): a planted package golden and a planted ledger file that quote a module stem leave the module's selection narrow (the two replays that import it, never `runtime/tests`), a data file outside those folders still links, and a vacuity case with `DATA_NAMING_SKIP` emptied selects the whole test folder, which proves the planted case exercises the rule.
- **Principle 13.** Saved: a change to a module that appears in a golden trace no longer runs the whole `runtime/tests` folder in the hook and in CI. None is: those files are read by the replays and the ledger tests, which `DATA_FOLDERS` selects when the file changes, and the replays reach the entry path modules through their imports (checked by the oracle test above).
