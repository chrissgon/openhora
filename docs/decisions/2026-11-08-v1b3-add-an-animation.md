## 2026-11-08: "Add an animation" in the runtime (V1b3; VD15; no measurement change, no skill changed, no lab run)

- `captions-edit` gains the closed edit kind `animation`: `{"op": "animation", "block", "params", "word_from", "word_to"}` adds a review-only beat, `{"op": "animation", "id", "remove": true}` removes one. It is stored in `review.json` (`animations`, an origin word range like an anchor) and never written into the post file (VD15).
- The renderer's checker is the only checker of a block's parameters: the runtime calls the host verb `block-params` of the renderer through `MediaEngine`, whose closed list gains that one word. `MediaEngine` keeps that verb's closed refusal line (a code and a parameter's name, never its value) so the person learns which parameter was refused.
- The runtime reads the generated `providers/renderer/blocks/catalogue.json` as data (V3b0's hand-off), only for a block's kind, preset and engines, and refuses it when its `blocks_sha256` is not the sha256 of `blocks/pins.json` (`catalogue_stale`).
- In M1 only overlays with a preset can be added: no layout (asset slots do not exist), no block of no preset (V3b0 OPEN-7, V3b OPEN-8), only a block the project's engine draws. Text parameters are made NFC and stripped before the check.
- `align` appends each animation to `beats.json` as an overlay `a<n>` with `beat` 1000 + n and score 1; one whose words were all cut stops the step (`animation_lost`), as a lost anchor does. Added animations and the script's beats that are not dropped are at most 12 (`limits.beats_max`).
- The operation `video-catalogue` (terminal and page, group `media`, class G, kind `internal`, catalog version 4) lists the blocks and whether each can be added now. It is our data and crosses the LAN socket (VD18); limit L68 is unchanged.
- Refusal codes: `animation_unavailable`, `unknown_animation`, `too_many_animations`, `bad_block`, `unknown_block`, `animation_kind`, `block_no_preset`, `slot_not_supported`, `block_not_on_engine`, `not_configured`, `bad_params`, `catalogue_unreadable`, `catalogue_stale`, `block_check_unavailable`, `block_check_failed`, and the renderer's own codes (`undeclared_param`, `missing_param`, `text_not_clean`, ...).
- Settled by the supervisor on the spec's recommendations (OPEN-1 to OPEN-13 of the V1b3 spec), not by the maintainer's word.
- Not done here: `block-params` on the HyperFrames engine (V4), picking the block of a script beat's preset (G14, V4), a preview of an added animation (later, loopback only by VD18), removing a recording (a later package), the page (V1c), the messaging path (V1d).
