- **What it is.** (1) `runtime/recurrence.py` and `runtime/registry/recurrence_words.json` (pt-BR and en, folded, sorted, checked by `registry_data.problems`): `mentions`, `read`, `words`, `which`, `week_range`, `strip`, `rule_word`. A repetition is read from closed phrases and only when it is one daily or one weekly repetition: a weekly one is on the weekday of the start, never another; an interval ("a cada 2 dias"), an end ("até dezembro", "por 3 semanas"), two weekdays, "todo dia 16", a month or a business-day rule are not read. (2) The row `event-create` takes `repeat` (typed, `daily` or `weekly`) and the v2 slot `repeat` (span). `ops_interpret._repeat` decides, for a new event from a line: a line that holds a repetition phrase of the closed lists (or that the time engine says repeats) opens a card only if code read the repetition (the model named its span, the time is the engine's, the span and the whole line read alike, the title holds none); otherwise the sentence `RECUR_NOT_READ` and no card, at version 1 too (OPEN-CB-13). The time span of a line whose recurrence words made the engine ask is read again with the words that only say it repeats set aside (`interpreter._check_op`, event-create only, accepted only when the second reading is clear). (3) The document gains two keys that exist only when they apply (`recurrence`, `series`), so every other document has the key and the hash it always had (a test holds two keys computed by the code of 6f9df1b4); the operations `cancel-series` and `cancel-occurrence`; the cards say in words which they are. One occurrence is the one instance the provider lists for the day the engine reads from the person's words (never `time_iso`); the card names its date and time as the provider has them and says that the series stays. (5) The step re-reads the master or the instance (and refuses a series that is not a plain daily or weekly one, that the person does not organize alone, or one whose version moved); `effect_calendar.execute` reads it once more and compares version, series and start; the dry run and the confirmed run carry the same flags, both built from the approved document (`calendar_document.series_args`), and the preparation checks the dry run's `verb` and `guard` against what the document says.
