## 2026-10-28: T8-0a: the phrase kit, a test asserts a table key and its fields instead of a quoted sentence (T8-kit; SPEC-V3-STRUCTURE section 5, PLAN-BRAIN section 7 T8; tests only; no model call, no provider call, no lab run, fingerprint unchanged)

The first piece of T8 ("wording asserts move to phrase keys plus one snapshot per language"); the conversions (T8-1 to T8-5) wait for CB-9 to merge and the snapshot (T8-0b) comes with the first of them, as the spec's order says. This piece adds two files and changes none that exists: `runtime/tests/phrase_kit.py` and `runtime/tests/test_phrase_kit.py`, plus one paragraph of `runtime/README.md`.

- **The kit.** `said(text, key, cfg=None, **fields)` is true when a line of `text`, or the whole of it, is the sentence of `key` in the language of `cfg` with those fields; a field not given matches any text, a field given matches its text exactly (written as the template would write it, escaped: a point is a point); a field repeated in a template holds one value; a sentence of two lines matches whole or line by line; a key in the other language does not match; a language with no table, or a key it lacks, says the English sentence, as `phrases.text` does. `which(text, cfg=None)` returns `(key, {field: text})` for the sentence a text says, looked for in the language of `cfg` first and then in the others, the template with the most fixed characters first, so that a template of one placeholder and a colon does not swallow a sentence a more exact one says; `None` when none matches. `assert_said` is `said` or an AssertionError with the expected template (a field not given as `{field}`), the text (one line, at most 300 characters), and the nearest: the same key with another field value, the same key in the other language, the key the text does say, or the nearest sentence of the table by difflib. The first three arguments are positional only, because the real table has fields called `text`; a key the table lacks is a KeyError and a field the key lacks a ValueError, a typo in a test and never a quiet failure.
- **The parts.** The table is the core plus the parts of `runtime/phrases_parts/` (SPEC-HOTSPOTS): the kit reads `phrases.TABLE` as built, at the moment of the call, and writes no sentence of its own, so a sentence of a part is covered like one of the core. A test reads every `phrases_parts/<id>.en.json` and `<id>.pt-BR.json` and requires `said` to accept each key of each part in its language; a planted table that leaves the parts out makes the same check fail.
- **Where it lives, and what that costs.** `runtime/tests/phrase_kit.py` is where the spec puts it, and the selector treats a module that is not a test inside a `tests/` folder as a test kit, so a commit that adds or changes it selects the tests that import it.
- **Tests.** `runtime/tests/test_phrase_kit.py` swaps in a small table of its own (fictional sentences; the second language written without accents, because the repository's English check reads the file) so that the oracle is the test's literals and not the wording the kit will be used on: each language, a field that differs fails, a field not given matches, a repeated field, a regular-expression character in a template or in a value, a sentence of two lines, a line of a longer text, which in both languages and its order of templates, the messages of `assert_said`, the two kinds of error, a field called `text`, `key` or `cfg`. One test reads the real table and checks the kit against `str.format` for every sentence of both languages, with a field changed for each; another checks `which` on a sample. Vacuity: a `said` patched to ignore the fields fails the field checks, a `said` that always uses English fails the language checks, a `said` that treats the template as a regular expression fails the literal checks, a `which` that always answers the first key fails the naming checks, and a table without the parts fails the parts check.
- **Not done.** No conversion, no snapshot, no edit of `runtime/phrases.py`, and no change to a test that exists.
- **Principle 13.** Saved: nothing yet; the saving is the maintenance of the roughly 1,000 asserts the conversions will turn into keys. Given up: nothing; the kit reads the table, so a test converted to it is exactly as strict about a field as the quoted sentence was, and as strict about the wording as the one snapshot that pins it (T8-0b).
