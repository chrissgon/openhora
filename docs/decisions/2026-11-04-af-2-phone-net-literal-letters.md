## 2026-11-04: a phone-language template is a witness only when its own text holds four letters (AF-2 PHONE-NET; no model call, no provider call, no lab run)

**The fault.** `phone_errors.spoken` treats a text as already said in pt-BR when it fullmatches a template of the pt-BR table with its fields read as `.+?`. `SRC_TWIN` (`{name} ({detail})`), `FR_FOLDER` (`{folder} ({account})`), `TODO_ITEM` (`{n}. {title}`) and a few others hold almost no literal letters, so they match any text that ends in a parenthesis or starts with a number. An English refusal such as "that event is not on this calendar any more (it was removed, or it is on another calendar)" passed `safe` unchanged and reached a Portuguese phone (row 38b of the acceptance run of 2026-11-04).

**The change.** `_said_already` skips a template that has fields and whose own text, outside the fields, holds fewer than `WITNESS_LETTERS` (4) letters (`str.isalpha`). A sentence with no field is still matched as it is (`Sim`, the weekday abbreviations), because it matches only itself. The templates dropped as witnesses, measured on the table at the pinned commit: `CARD_BOX_DRAFT_BCC`, `CARD_BOX_ITEM`, `DONE_LINE`, `FR_FOLDER`, `FR_HEAD_ACCOUNT`, `FR_ITEM_ACCOUNT`, `HEADER`, `LP_VALUE_ACCOUNT`, `LP_VALUE_CLOCK`, `LP_VALUE_DAY`, `LP_VALUE_WEEKDAY`, `MR_HEAD`, `MR_ROW`, `NT_WHEN_FAR`, `NT_WHEN_REL`, `NW_ITEMS_EW_DAY`, `NW_ITEMS_MATCH_WORDS`, `NW_ITEMS_RL_DAY`, `NW_ITEMS_WHEN_TODAY`, `SRC_ITEM_CARD`, `SRC_TWIN`, `TODO_ITEM`, `UNDERSTOOD_FROM_ACCOUNT`, `UNDERSTOOD_ON_DAY`. A sentence that stays a witness is one like `CARD_ACCOUNT` ("Conta: {account} ({address})"). A text with a letter only Portuguese uses is still taken as said already, as before.

**Alternative rejected.** Dropping the field-less short sentences too: they match only themselves, so they cannot leak, and dropping them would turn a plain "Sim" or "seg" into the failure sentence.

**What does not change.** No approval check, no card hash, no phrase key and no phrase text; an English phone is untouched. No golden replay row moved.
