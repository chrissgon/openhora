## 2026-10-28: T8-2: the calendar and event tests assert phrase keys and fields, not quoted sentences (SPEC-V3-STRUCTURE section 5; tests only; no model call, no provider call, no lab run, fingerprint unchanged)

The second family of T8 after the kit (T8-0a): `test_calendar_*` and `test_event_*` (12 files: 10 with a sentence to convert; `test_calendar_list_words.py` and `test_event_lookup_day_shapes.py` read no table sentence). A sentence of the phrase table that a test quoted is now `pk.said(text, "KEY", cfg, field=value)` (or the whole-reply form below); no test was removed or merged and no product file changed.

- **Counts.** 242 assert statements changed in 10 files (an assert counted once when its text differs from the one at the base): `test_calendar_recheck.py` 7, `test_calendar_refs.py` 4, `test_calendar_write.py` 29, `test_event_change_by_name.py` 33, `test_event_list_pick.py` 25, `test_event_lookup.py` 36, `test_event_lookup_number_account.py` 43, `test_event_lookup_own_events.py` 43, `test_event_lookup_target_day.py` 2, `test_event_revise_flow.py` 20. The spec's count for these files (the AST scan of fragments of 14 characters or more) was 99; the rest are card labels shorter than that (`Title: `, `When: `, `Event: `, `Account: `), sentences kept in module constants and helper oracles (`card_problems`, `problems`, `account_line`, `OLD`) that the scan does not see.
- **Whole replies.** `said` finds a sentence as one line of a longer text, so it is looser than a `reply == "<sentence>"` it replaces; `test_event_lookup.py` has `alone(text, key, cfg, **fields)` (one line, nothing else) and `says(text, (key, fields))`, which the other event files import. The module constants that held a sentence (`CARD_2`, `NO_SOURCE`, `AGAIN`, `ASK_AGAIN`, `CHECK_FAILED`, `NOT_READABLE`, `HINT`, `FOUND`, `NONE`, `CANNOT`, `PAST`, `ALL_DAY`, `WHAT`, `NO_MICROSOFT`) are now `(key, fields)` pairs; so are the expected lines of a card (`OUTLOOK_ID`, `BEFORE`, `AFTER`, `new_event_card`), compared line by line through `pk.which(line, cfg)` where the whole card was compared before.
- **Kept literal.** The rows of a list (`2. Thu 22/10/2026 13:00-14:00 · corte de cabelo`) are data built by code, not table sentences, and stay literal with a comment; the lines a person types stay (they are the input); log lines and error text that are not in the table stay. One sentence stays as a constant, `CARD_SENT` of `test_event_lookup_number_account.py`, because `test_phone_outlook_remove.py` (T8-1's file) imports it as a string; this file asserts the pair `CARD_1`, and T8-1 can drop the constant when it converts that file.
- **The language of a check.** The cards are English in every test (the card's hash is of the English body), the chat replies of the event tests are pt-BR unless a test builds an English project, so `CFG` and `PT` are two literals in each file.
- **Vacuity (sampled, planted in the product code and put back).** A key switched (`EV_CHANGE_WHAT` answered as `EV_ASK_DAY`): the bare-number test fails. A field off by one (`days=WINDOW_DAYS + 1`): five tests fail. A card field changed (`CARD_CAL_EVENT` with a prefix on the event id): four tests fail. A wording changed in both languages (`EV_CHANGE_WHAT`, `EV_NAME_NONE`, `CARD_CAL_NOBODY`): 234 converted tests still pass, as the spec's third case asks; the snapshot that pins the wording (T8-0b) is not built yet.
- **What did not hold.** `phrase_kit.which(text)` with no language tries English first, and the English template `{n}. {title}` swallows a whole pt-BR sentence before the exact pt-BR key is looked at, so a `which` on a pt-BR reply needs the pt-BR `cfg`. `phrase_kit` has no "the whole text and nothing else" form (above). `architecture_tables.py --check` fails at the base of this branch (the generated blocks of `docs/architecture/platform/runtime.md`), not because of this change.
- **Principle 13.** Saved: the maintenance of about 240 asserts that broke on every rewording of a card or a reply. Given up: an assert on a line of a longer text is as strict as the sentence it replaces only through `alone`; the kit itself reads the table, so the wording is pinned by the snapshot (T8-0b) alone.
