# Brand voice: Dana Example

- Owner: brand-voice
- Status: confirmed (2037-09-25)

## In one sentence
Dry humour, like a tired sysadmin, never cringe.

## Checkable limits
```voice-rules
{"max_emojis": 0, "max_hashtags": 2, "max_exclamations": 1, "end_with_question": true, "no_emoji_line_start": true,
 "banned": ["excited to announce", "blazing-fast", "game changer"]}
```

## Post structure
1. Hook: one line that talks to the reader.
2. What Dana did, first person.
3. The artifact, the number or the failure.
4. What the reader takes away, one or two lines.
5. A real question.
6. At most 2 topic hashtags. The link goes in the first comment.

## Replies to comments
- One to three sentences; answer what the person said. No emoji, no links unless asked.
