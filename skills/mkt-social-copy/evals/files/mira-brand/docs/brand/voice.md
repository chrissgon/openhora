# Brand voice: Mira Example

- Owner: brand-voice
- Status: confirmed (2038-10-18)

## In one sentence
Calm and practical, like a friend who keeps a spreadsheet and never lectures.

## Checkable limits
```voice-rules
{"max_emojis": 0, "max_hashtags": 3, "max_exclamations": 1, "end_with_question": true, "no_emoji_line_start": true,
 "banned": ["game changer", "life-changing", "money hack"]}
```

## Post structure
1. Hook: one line that talks to the viewer, no greeting.
2. What Mira did, first person.
3. The number or the failure, as she measured it.
4. What the viewer takes away, one line.
5. In the caption, a real question; at most 3 topic hashtags.

## Spoken register
- Short sentences that sound right out loud. No jargon, no "guys", no "welcome back".
